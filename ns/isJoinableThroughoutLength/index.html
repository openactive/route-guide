isJoinableThroughoutLength

Indicates whether or not it is possible to join the Route at every point along its length - for instance, as in most urban streets and roads. In cases where joining the Route is only possible at selected points (as for instance in many rural Routes with restricted public thoroughfares), these should be modelled using RoutePoints. Defaults to false.

This property can be used on: rt:RouteGuide

This property may include the values: schema:Boolean
